# Asset provenance

The included icon.svg, Canvas constellation, Canvas floating city, CSS visual system, fixture suggestions and documentation were created for this package. No external stock images, fonts, music or character assets are included. System fonts are used. No image generation service was used for the code-native visuals.

The code uses Node and browser platform APIs. No runtime dependency is bundled. Optional browser QA uses Playwright installed separately under its own license. Models, Twitch, Node, OBS and other services retain their respective terms and trademarks.

Before adding assets, record filename, author/source, license, permitted usage and modifications. Do not treat “found online” as a license.

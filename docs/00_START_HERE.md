# Read this first

## Your product

ChatAtlas Foundry is an audience co-creation loop, not a general-purpose chat summarizer. The working scenario asks a Twitch community to design a floating city that survives a storm. Themes preserve different ideas; a host decides what to adopt; the city must demonstrate the consequences.

## Definition of competition readiness

The code package is ready to run locally. The competition entry becomes ready only after you authorize a real channel, collect real viewer contributions, record actual Twitch operation, test your chosen model configuration if used, and publish truthful submission materials. Keep a final source commit and actual Codex session ID. Do not insert invented results or testimonials.

## Recommended first session

Run the offline storm example, inspect the engine tests, configure a separate live data directory, connect your channel, then ask a small consenting audience for ideas. The highest-value next work is that real session; it will reveal more than another speculative feature list.
